# MirrorLite 安卓 USB 投屏 —— 1.0 正式版

由于市面上的手机投屏电脑软件要么免费但延迟大帧率低，要么需要付费，于是我决定挫一个手机投屏的软件。

这是一个把安卓手机画面通过 USB 投到 Windows 的小工具：低延迟、60 FPS 以上、带声音、
鼠标可以直接操作手机。不需要 root，不需要装手机端 App。

## 使用方法

1. 手机用 USB 数据线连到电脑
2. 打开手机的「开发者选项」-「USB 调试」（vivo/小米/OPPO 还要开「USB 调试（安全设置）」）
3. 手机上弹出「允许 USB 调试吗」时点「允许」
4. 双击「启动投屏.cmd」

## 窗口里能做什么

左键单击     = 手机上点一下
按住拖动     = 滑动 / 拖拽
滚轮         = 上下滚动
F11          = 全屏切换
F1           = 显示 / 隐藏左上角状态信息
Esc          = 退出

手机横过来看视频时，窗口会自动变成横屏比例（竖屏同理），不会出现
「竖屏窗口里只显示中间一条横屏画面、四周全黑」。全屏状态下窗口尺寸不变，
画面按比例居中。

## 运行环境

Windows 10 1809 及以上（需要 D3D11），64 位
手机 Android 5.0 及以上；已在 Android 16 的 vivo 机器上实测

## 包里都有什么

mirror.exe              主机端程序
mirror-server.jar       推到手机上的服务端（由程序自动推送，勿删）
adb.exe / AdbWin\*.dll   与手机通信，来自 Android SDK platform-tools
avcodec / avutil / swscale / swresample  FFmpeg 解码库（LGPL）

整个文件夹要放在一起，不能只拷 mirror.exe。

## 常见问题

* 窗口左上角显示「未检测到设备」/ 彩条画面
→ adb 没连上：确认数据线、USB 调试已开、手机已授权；可在命令行跑 adb devices 检查
* 连上了但一直是黑的，左上角提示「等待首帧」
→ 手机息屏或锁屏了，点亮屏幕即可；投屏时别锁屏
* 画面长时间不动后不再刷新
→ 正常：手机画面没变化时系统不重新合成，鼠标动一下就会恢复
* 没有声音
→ 部分机型不允许捕获系统声音，程序会照常投画面；看左上角音频那一行的提示
* 双击后黑窗口一闪就没了
  → 早期版本的启动脚本有编码问题（cmd 按错误编码解析导致立即退出），现已修复
  → 如果仍然闪退，在文件夹里按住 Shift 右键「在此处打开 PowerShell 窗口」，
    输入 .\启动投屏.cmd 回车，就能看到具体报错

* 双击后提示「没有检测到已授权的安卓设备」
  → 窗口里会直接显示 adb 看到的原始信息，并按 unauthorized / offline / 空列表给出对应建议
  → 同时会把这份信息存成「诊断信息.txt」，发我就能定位

* 报错里出现 adb.log / Permission denied / failed to start daemon
  → 是系统临时目录里的 adb.log 不可写，导致 adb 服务起不来
  → 已把 adb 的临时目录改到程序目录下的 adb-tmp 文件夹（首次运行会自动创建），
    这个文件夹可以随时删掉，程序下次运行会重建

* 提示 adb 相关错误、端口被占用
→ 关掉其它手机助手/投屏软件（它们会抢占 adb），再重试

## 已知限制

* 只支持 Windows；只做鼠标，键盘输入还没做
* 多指手势（双指缩放）未支持
* 极少数机型不允许虚拟显示或音频捕获，会退化成只能看画面

## 技术说明

手机端以 shell 权限运行一个 app\_process 服务，用 MediaCodec 硬件编码 H.264，
通过 adb 的 localabstract 通道传到电脑，电脑端 FFmpeg 解码 + D3D11 渲染，

音频是 Opus 经 WASAPI 播放。实测 864x1920 下平均 116 fps、帧间隔 P99 24.8 ms。
